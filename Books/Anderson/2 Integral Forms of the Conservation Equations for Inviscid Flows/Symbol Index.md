# Symbol Index — Anderson, Chapter 2

| Symbol                        | Meaning                          | Description                                                                                                                                               | Value | Units                    | SI Base Units                          |
| ----------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ------------------------ | -------------------------------------- |
| $\dot{m}$                     | Mass flow rate                   | Mass flow rate through an oriented surface element, $\dot{m}=\rho\,\mathbf{V}\cdot d\mathbf{S}$.                                                          |       | $\mathrm{kg/s}$          |                                        |
| $\dot{m}_e$                   | Exit mass flow rate              | Mass flow rate at the engine/nozzle exit in the thrust equation.                                                                                          |       | $\mathrm{kg/s}$          |                                        |
| $\dot{m}_i$                   | Inlet mass flow rate             | Mass flow rate entering the control volume at the inlet in the thrust equation.                                                                           |       | $\mathrm{kg/s}$          |                                        |
| $\dot{q}$                     | Heat-addition rate per unit mass | Volumetric heat-addition model: heat added per unit mass per unit time.                                                                                   |       | $\mathrm{W/kg}$          | $\mathrm{m^2\cdot s^{-3}}$             |
| $\dot{Q}$                     | Heat-transfer rate               | Net heat transferred to the control volume (e.g., conduction/diffusion/radiation), used in the generalized energy equation.                               |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $\dot{W}$                     | Power                            | Generic mechanical power (rate of doing work), $\dot{W}=\mathbf{F}\cdot\mathbf{V}$.                                                                       |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $\dot{W}_{\text{shaft}}$      | Shaft-work rate                  | Power transferred via a rotating shaft crossing the control surface (generalized energy equation).                                                        |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $\dot{W}_{\text{viscous}}$    | Viscous-work rate                | Power due to viscous stresses acting on the control surface (generalized energy equation).                                                                |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $\mathbf{a}$                  | Acceleration                     | Material/particle acceleration in $\mathbf{F}=m\mathbf{a}$.                                                                                               |       | $\mathrm{m/s^2}$         |                                        |
| $\mathbf{A}_1$                | Momentum-flux term               | Net rate of momentum flow across the control surface, $\mathbf{A}_1=\iint_S(\rho\mathbf{V}\cdot d\mathbf{S})\mathbf{V}$.                                  |       | $\mathrm{N}$             | $\mathrm{kg\cdot m\cdot s^{-2}}$       |
| $\mathbf{A}_2$                | Unsteady momentum term           | Time rate of change of momentum stored in the control volume, $\mathbf{A}_2=\frac{\partial}{\partial t}\iiint_{\mathscr{V}}\rho\mathbf{V}\,d\mathscr{V}$. |       | $\mathrm{N}$             | $\mathrm{kg\cdot m\cdot s^{-2}}$       |
| $\mathbf{F}$                  | Net force                        | Net external force acting on the control-volume fluid (body + surface forces).                                                                            |       | $\mathrm{N}$             | $\mathrm{kg\cdot m\cdot s^{-2}}$       |
| $\mathbf{f}$                  | Body force per unit mass         | Body force per unit mass (e.g., gravity), used in $\iiint_{\mathscr{V}}\rho\mathbf{f}\,d\mathscr{V}$.                                                     |       | $\mathrm{m/s^2}$         |                                        |
| $\mathbf{F}_{\text{viscous}}$ | Viscous surface force            | Net viscous force on the control surface when viscosity is included in the momentum equation.                                                             |       | $\mathrm{N}$             | $\mathrm{kg\cdot m\cdot s^{-2}}$       |
| $\mathbf{V}$                  | Velocity                         | Fluid velocity vector field; $\mathbf{V}\cdot d\mathbf{S}$ sets the signed volumetric flux.                                                               |       | $\mathrm{m/s}$           |                                        |
| $\mathscr{V}$                 | Control volume                   | Fixed spatial region occupied by the control volume (integration domain for $\iiint_{\mathscr{V}}$).                                                      |       | —                        |                                        |
| $\rho$                        | Density                          | Fluid density.                                                                                                                                            |       | $\mathrm{kg/m^3}$        |                                        |
| $\theta$                      | Angle for surface projection     | Angle between $\mathbf{V}$ and the outward normal direction.                                                                                              |       | $\mathrm{rad}$           |                                        |
| $A_e$                         | Exit area                        | Nozzle/engine exit plane area used in the thrust equation.                                                                                                |       | $\mathrm{m^2}$           |                                        |
| $A_i$                         | Inlet area                       | Engine inlet plane area used in the thrust derivation.                                                                                                    |       | $\mathrm{m^2}$           |                                        |
| $B_1$                         | Heat-addition rate term          | Rate of heat added to the control-volume fluid from the surroundings (control-volume first law).                                                          |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $B_2$                         | Work rate term                   | Rate of work done on the control-volume fluid (pressure work + body-force work in this chapter’s model).                                                  |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $B_3$                         | Energy-change rate term          | Rate of change of the fluid energy as it flows through the control volume (storage + flux).                                                               |       | $\mathrm{W}$             | $\mathrm{kg\cdot m^2\cdot s^{-3}}$     |
| $c_v$                         | Constant-volume specific heat    | For a calorically perfect gas, $e=c_vT$.                                                                                                                  |       | $\mathrm{J/(kg\cdot K)}$ | $\mathrm{m^2\cdot s^{-2}\cdot K^{-1}}$ |
| $d\mathbf{S}$                 | Differential area vector         | Oriented surface element $d\mathbf{S}=\mathbf{n}\,dS$ pointing outward from the control surface.                                                          |       | $\mathrm{m^2}$           |                                        |
| $d\mathscr{V}$                | Differential volume              | Differential volume element in volume integrals over the control volume.                                                                                  |       | $\mathrm{m^3}$           |                                        |
| $dS$                          | Differential area (scalar)       | Magnitude of a small control-surface element.                                                                                                             |       | $\mathrm{m^2}$           |                                        |
| $e$                           | Internal energy per unit mass    | Thermodynamic internal energy (not including kinetic energy).                                                                                             |       | $\mathrm{J/kg}$          | $\mathrm{m^2\cdot s^{-2}}$             |
| $m$                           | Mass                             | Mass of a body (or lumped mass used in Newton’s second law statements).                                                                                   |       | $\mathrm{kg}$            |                                        |
| $p$                           | Pressure                         | Thermodynamic pressure; produces surface force $-p\,d\mathbf{S}$ and pressure work in the energy equation.                                                |       | $\mathrm{Pa}$            | $\mathrm{kg\cdot m^{-1}\cdot s^{-2}}$  |
| $p_\infty$                    | Ambient (freestream) pressure    | Outside/ambient pressure used in the thrust equation and control-volume model.                                                                            |       | $\mathrm{Pa}$            | $\mathrm{kg\cdot m^{-1}\cdot s^{-2}}$  |
| $p_e$                         | Exit pressure                    | Static pressure at the exit plane in the thrust equation.                                                                                                 |       | $\mathrm{Pa}$            | $\mathrm{kg\cdot m^{-1}\cdot s^{-2}}$  |
| $R$                           | Specific gas constant            | Gas constant per unit mass in the ideal-gas equation of state $p=\rho RT$.                                                                                |       | $\mathrm{J/(kg\cdot K)}$ | $\mathrm{m^2\cdot s^{-2}\cdot K^{-1}}$ |
| $S$                           | Control surface                  | Closed surface bounding the control volume (integration domain for $\iint_S$).                                                                            |       | —                        |                                        |
| $t$                           | Time                             | Time variable in unsteady terms such as $\partial/\partial t$.                                                                                            |       | $\mathrm{s}$             |                                        |
| $T$                           | Temperature                      | Thermodynamic temperature appearing in $p=\rho RT$ and $e=c_vT$.                                                                                          |       | $\mathrm{K}$             |                                        |
| $T$                           | Thrust                           | Engine thrust (scalar) in the jet/rocket thrust equations.                                                                                                |       | $\mathrm{N}$             | $\mathrm{kg\cdot m\cdot s^{-2}}$       |
| $V$                           | Speed                            | Magnitude of the velocity, used in kinetic energy $V^2/2$ and projections $V\cos\theta$.                                                                  |       | $\mathrm{m/s}$           |                                        |
| $V_\infty$                    | Freestream speed                 | Freestream/inlet speed used in the thrust equation derivation.                                                                                            |       | $\mathrm{m/s}$           |                                        |
| $V_e$                         | Exit speed                       | Exhaust speed at the exit plane in the thrust equation.                                                                                                   |       | $\mathrm{m/s}$           |                                        |
| $V_n$                         | Normal velocity component        | Component of velocity normal to the surface element, $V_n=V\cos\theta$.                                                                                   |       | $\mathrm{m/s}$           |                                        |
